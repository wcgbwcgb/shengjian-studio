# 声间 · AI 视频创作空间

原生 HTML / JavaScript 前端，Python / FastAPI 后端，SQLite 保存项目、任务和版本，FFmpeg 处理本地媒体。

当前优先保证调研、文案、素材组织和剪辑。**新任务不执行 ASR、字幕对齐或自动字幕生成，导出不包含新字幕文件。** 历史版本和已有成片继续保留。

## 开始使用

1. 安装 Python 3.11+，双击 `启动工作台.cmd`。首次启动安装依赖。
2. 配置 FFmpeg / ffprobe；可以在设置中填写本地路径。
3. 调研与文案可以使用本机 Claude Code 的订阅登录，也可以在「调研与文案服务」切换回 API；直接视频制作使用同一本机 CLI。
4. 打开 http://127.0.0.1:8765。更新后重启服务。默认仅监听本机，不支持同时启动多个服务进程。

Mac：双击 `安装.command`（如被系统拦截：打开「终端」，输入 `bash `，把 `安装.command` 拖进窗口后回车）。它会安装 Homebrew、Python、FFmpeg、Node.js、Claude Code 和依赖，引导登录 Claude，然后打开工作台；以后双击 `启动工作台.command`。需要管理员账户和自己的 Claude 订阅。打包给别人：`git archive --format=zip --prefix=声间/ -o 声间-mac.zip HEAD`。

开发者启动：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

## 创作流程

首页提供新建项目、继续最近项目和从已有素材开始。

- **直接制作视频**：输入内容、画面与节奏要求。按钮和 Ctrl+Enter 执行相同流程。本机 CLI 制作完整视频；继续提出修改会生成新版本。缺少 CLI 时保存项目并明确提示配置，不会假装正在制作。
- **先研究与写稿**：可直接使用 Claude 订阅，无需 API Key。（可选）先聊清楚需求 → 研究来源与方向 → 选择、追加或自己写方向 → 编辑脚本 → 在视频页写制作要求 → Claude 制作完整视频。脚本不会自动附带给 Claude，需要时把要点写进要求。脚本支持角色、段落编辑、锁定、局部重写、模型和模板选择、历史恢复、Markdown 拍摄包导出。
- **从已有素材开始**：上传默认归属新建项目，完成后进入视频页，写下要求后再开始制作。

### 视频页：制作要求

视频页只有一段制作要求（prompt）。工作台把这段文字原样交给本机 Claude Code（默认 Opus、effort medium，可在设置中调整；不沿用终端里的 effort 设置），不附加任何规则、格式要求或项目默认设置，效果与在终端里直接对 Claude Code 说这句话相同。

- **工作文件夹**：每个项目一个，位于 `data/projects/<项目>/claude/`。Claude 在这里自由工作，后续修改会接着上一次的对话继续。这个文件夹在工作台仓库里面，所以视频任务关闭了 Claude Code 的自动记忆，免得 Claude 读到（或写入）开发工作台时留下的记录。
- **素材**：项目素材按原文件名复制到工作文件夹的 `素材/` 目录（只读）。想怎么用直接写在要求里，例如「用素材里的 main.mp4 开头」。
- **制作能力**：`agent-ability/` 里每个 md 文件是一份可选的做法说明，发送前的弹窗里显示为一个勾选项（名称取文件第一行标题）。勾选后，完整原文末尾会多一行，让 Claude 先读这个文件；不勾选就不发。目前有两项。`optimized-audio.md`（优化音频生成速度）：卷积用 FFT 等。`fast-render.md`（加快渲染与编码）：Remotion 用显卡、Python 逐帧多进程、网页截帧用 `agent-ability/tools/html-frames.mjs` 并行截帧边截边编码，在本机实测把渲染缩短到原来的 1/2.6 至 1/3.8。浏览器会记住上次的勾选。放入新的 md 文件就会多一个勾选项；`tools/` 子文件夹放指南用到的脚本，不会显示为勾选项。
- **取回成片**：Claude 结束后，工作台取本次运行中最新写出的视频文件，保存为新版本（`videos/<任务>/video.mp4`）。不是网页可播放的 H.264 MP4 时，工作台自动转换一份；全范围的 `yuvj420p`（由图片帧合成或 Remotion 默认输出）可以直接播放，不再转换。没有生成视频时，任务失败并显示 Claude 的回复；中途停止但已有视频时，保留该视频并在制作记录中注明。

快捷按钮可以预填「剪辑我的素材」「参考一个视频」「从零生成」三类要求。已有版本时，可以选择在当前版本上修改，或重新制作一版。

「高级选项：按分镜手动组装」默认收起，保留原来的脚本 → 分镜 → 本地初剪流程。分镜缺画面时会生成明确标注的文字卡。

### 制作权限

视频任务以 `dontAsk` 模式运行 Claude Code 的全部工具（含联网搜索、读取网页、子代理），由 PreToolUse hook（`app/cli_guard.py`）放行。hook 只拦截以下操作：

- 删除、移动或重定向写入工作文件夹、toolbox 和临时目录以外的文件；
- 修改工作文件夹里的 `素材/` 副本；
- 修改系统设置（磁盘、注册表、服务、计划任务、关机等）、按进程名结束进程、全局安装依赖、修改工作台自身的 Python 环境；
- 读取凭据和工作台私有数据（`.env`、`machine-config.json`、`workbench.sqlite3`、`~/.ssh` 等）；
- 对外发布（`git push`、`npm publish`、`gh`）。

依赖、浏览器和可复用模板保存在 `.runtime/agent-toolbox`（独立 Python 虚拟环境、pip / npm / Playwright 缓存），所有任务共用。建议安装 Node.js，以便 Claude 使用 Remotion 或 HTML 动画制作动态图形。hook 检查的是工具调用本身，不检查 Claude 写入脚本后再执行的代码，因此不是操作系统沙箱。

默认上限为 300 轮、120 分钟，可在设置中调整（最多 2000 轮、360 分钟）。工作台本身不做 ASR 和字幕文件；视频任务也不再禁止 Claude 这样做，是否转写由要求决定。

### 明确需求与方向

首页「先帮我理清需求」默认开启（选择保存在浏览器，从灵感开始的项目同样适用）。开启时，「先研究与写稿」不会直接研究，而是先由 Claude 一次问一个问题，给 2–4 个可点选的回答，也可以自由输入。确认的内容写入「需求卡」（给谁看、目的、核心观点、语气、形式、必须包含、要避免、其他），可以直接修改。Claude 判断需求清楚后会提出「开始研究」按钮；也可以随时点「够了，开始研究」。研究提示词会带上需求卡。

研究完成后，方向不限于最初三个：

- **再给几个方向**：可以写一句不满意的地方，只用已有研究资料重新构思，不重新搜索；新方向会避开已有方向。
- **自己写一个方向**：用你写的方向和已有研究资料直接写脚本。
- **调整后再用**：选某个方向，补充调整要求后写脚本。
- **和 Claude 聊聊**：研究和脚本阶段右下角的对话面板延续同一段对话。Claude 会根据阶段提出可执行的建议（重新研究、重新构思方向、按某个方向写脚本、修改脚本），点击按钮才会执行。

对话、追加方向和需求卡都保存在项目里。对话每轮是一个项目任务；研究或写稿进行中时不能发送新消息。

### 灵感发现

灵感按批次生成，不再汇总所有项目的研究结果，也没有固定的起点题目。

- **换一批**：不联网，按方向关键词和设置里的受众、风格快速发散。
- **联网找近期热点**：联网搜索近期真实讨论后提出选题，附来源；检索记录中没有的来源标为「未核实」。
- **这一批哪里不喜欢**：反馈会用于之后的批次。「不感兴趣」会移除卡片，并让之后的批次避开类似题目。
- 换一批时，没收藏的卡片会被替换；「换回上一批」可以撤销一次（再点一次换回来）。收藏单独保存，不受换批影响。

灵感生成不属于任何项目，同一时间只能生成一批。来源只作为参考，事实、日期和指标仍需核对原文。

「精细调整时间线」保留视频预览、时间线 JSON 校验、素材分析、版本比较与高清导出。发布记录保留手动记录链接与指标的能力。

## 素材管理

归属和类型分别保存：

- **项目素材**：项目内上传默认归属当前项目。
- **公共素材库**：素材库上传默认归属公共库，可添加副本到项目。
- **类型**：Video、Image、Audio、Music。默认按格式识别，音乐须显式选择 Music；普通音频默认为 Audio。

素材可以在项目和公共库之间移动，保留 ID、原文件和物理存储位置，历史视频继续可用。类型与文件格式须兼容。相关任务运行期间不能改动素材；移动后受影响的分镜和剪辑会标记需要更新。

Music 的完整保护和原始增益依据素材自身类型判断。项目初剪会完整保留 Music；其他素材可手动指定保护区间。旧素材在启动时补齐归属、类型和存储信息。

## 服务、模型与设置

本机已将调研和文案切换为 Claude 订阅 Sonnet，视频仍使用 Opus。实现与真实连接验收边界见 [SUBSCRIPTION_VALIDATION.md](SUBSCRIPTION_VALIDATION.md)。

「调研与文案服务」可选择 Claude 订阅或 API。订阅默认用 Sonnet，允许单独选择 Opus / Haiku；版本别名由 CLI 解析。调研只开放网页搜索与读取，文案不给予文件或命令工具。使用登录检查确认 claude.ai 账号，不读取或转存 OAuth 凭据，不回退到 API Key。订阅调用保存 CLI 报告的用量，独立于工作台 API 预算。

「AI 服务与模型」统一管理 Provider、API 地址、密钥、各阶段模型和计费单价。OpenAI 使用 Responses 接口，Claude 使用 Anthropic Messages；模型选择只显示对应 Provider 支持的项目模型。兼容服务还须实际支持所选模型。

AI 服务、创作偏好和预算分别保存。保存一组不会保存或丢弃其他组尚未确认的输入。计费单价可按连接调整，费用是估算值，不代替服务账单。

提交 API 任务时冻结 Provider、接口地址、连接、密钥、模型、计费、预算和输出上限，并保存项目、素材、来源及上游快照。修改或删除全局连接不会改变已提交任务；重试沿用原快照。旧版没有完整连接快照的任务，在第一次重试时冻结当前兼容连接。

API 密钥不回显，不进入项目详情、版本或发布包。Windows 优先使用当前用户的 DPAPI；缺少加密环境时延续本地配置文件存储。任务凭据保存在单独的私有 SQLite 表，因此备份应包括整个 data 目录。跨用户/电脑迁移加密配置后需要重新配置连接。

同一项目一次执行一个任务。失败保留错误和已返回用量，支持取消、恢复与重试。服务退出后不继续运行，重新启动将未完成任务标为中断。调研、文案与视频的 CLI 配置均随任务冻结，账号额度与 API 预算分别记录。

CLI 的输入副本、脚本和输出位于项目任务目录。权限 hook 不是操作系统沙箱，本版面向本机可信项目。CLI 安装、登录、模型和账单由该账号管理。

## 保存与备份

- `data/workbench.sqlite3`：项目、版本、任务、素材元数据、来源、用量和私有任务凭据。
- `data/machine-config.json`：本机服务连接与工具配置。
- `data/projects/<项目ID>/`：项目素材、分析结果、版本输出和 CLI 工作目录。
- `data/library/`：公共库上传文件；移动素材不会改变原始存储目录。

停止服务后备份整个 `data` 目录。原文件和历史版本不覆盖。
